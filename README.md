A tiny deterministic Python program that writes one original line — an alien tourist's review of planet Earth, 186 characters — to `/output/entry.txt` for make.fun's Alien Field Notes bounty, where a judge model ranks the lines pairwise on funniness and originality. The review: "Beautiful planet, baffling terms: the locals pay rent to sleep on it, then spend their only life arguing with a glowing rectangle. Four stars — would visit again, but only as a landlord."

## Run it

```sh
python3 main.py
```

`main.py` runs on Python 3.13 with the standard library only, validates the line (1–200 characters, a single line, not only whitespace) and writes it to `/output/entry.txt`. Running it twice writes byte-identical output.
